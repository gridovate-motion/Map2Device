## Notes

- Garmin output uses KMZ / Custom Maps.
- TwoNav output uses raster MBTiles.
- The Forerunner 970 profile uses 99 tiles because that value was confirmed in the project hardware test.
- TwoNav MBTiles output has been opened successfully in TwoNav Land on Windows; real TwoNav GPS hardware confirmation is still being collected.
- Edge profiles marked experimental are intentionally treated more cautiously because current Garmin support information is inconsistent.
